# 🤖 Build Tinko for Real

Learn Python, build a real AI agent with it, then give that agent a robot body, all by building **Tinko**,
the friendly AI agent from the YouTube series *Agents, End to End*.

Every episode = a short story video + a step-by-step build video + **the code in this repo**.
Everything here is free, and every example is tested before it's released.

📺 **Videos:** [No Lectures, Just Stories on YouTube](https://www.youtube.com/@NoLecturesJustStories)

## The journey

| Season | You learn | You build |
|--------|-----------|-----------|
| 🐍 **A: Tinko Learns Python** | Variables, loops, functions, files, errors, APIs, classes | *Tinko's Toolkit*: a Python program that grows every episode |
| 🧠 **B: Tinko Gets a Brain** | Calling an AI, tool calling, the agent loop, memory, RAG, planning, MCP, guardrails, evals, LangGraph, CrewAI | *Study Buddy Tinko*: an agent that answers questions from your own notes, online |
| 🤖 **C: Tinko Gets a Body** | Sensors, motors, PID control, navigation, computer vision, robot safety | A simulated robot (Webots) that follows plain-English commands |

Episodes are added as they're released. Each one has its own folder: `season-x/ep-NN-topic/`, with
`starter/` (fill in the gaps), `finished/` (the full solution), a cheat sheet, and a challenge.

## What you need

- A laptop (Windows, macOS or Linux) and curiosity.
- Everything else is free: [Python](https://www.python.org/downloads/) 3.10+, [VS Code](https://code.visualstudio.com/),
  [Ollama](https://ollama.com/) (Season B, a free AI model on your own laptop) and [Webots](https://cyberbotics.com/) (Season C).
